Description:
This repository contains the initial implementation of my PhD project "A Systemic Approach for Identifying Parameter Errors in Simulation Models of Power Systems Using Machine Learning"

Status:
The project is currently under development. Some features may be incomplete or subject to change.

Contents:

1) ANATEMstb.py: A class for handling ANATEM files, like .stb, .cdu and .plt.
2) 01_GerarArq_Casos03_14BARRAS_Rev06.py: Generates the simulation database based on the files contained in the "ArqANATEMOrig" folder.
3) ArqANATEMOrig: A folder contains all original files ANATEM for reference.
